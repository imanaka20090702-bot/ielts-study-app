# ielts-study-app

IELTS対策アプリ（Reading能力向上機能つき）のシンプルなWeb実装です。

## 収録機能

- 段階的カリキュラム（初級/中級/上級、達成度に応じた次ステップ）
- 語彙学習（難語・意味・例文、フラッシュカード、習熟度記録）
- 速読トレーニング（時間制限、WPM計測、速度/正確性分析）
- 読解スキル別進捗（Skimming / Scanning / Detailed Reading）
- 弱点克服（誤答タイプ記録、集中練習コース推奨）
- 学習統計（学習時間、正答率推移、得意/不得意、スコア予測）
- クイズ/テスト（10分ミニ、セクション別、Full-length、即時FB）
- モチベーション維持（連続日数、バッジ、目標設定、推奨スケジュール）
